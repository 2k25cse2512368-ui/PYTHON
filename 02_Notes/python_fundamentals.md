# Python Fundamentals Notes

## Introduction

Python is a general-purpose, high-level programming language and is recommended as a first programming language for beginners.

## Applications

- Desktop applications
- Web applications
- Database applications
- Network programming
- Games
- Data analysis
- Machine learning
- Artificial intelligence
- IoT

## Core Features

- Simple and easy to learn
- Free and open source
- High-level
- Platform independent
- Portable
- Dynamically typed
- Procedure-oriented and object-oriented
- Interpreted
- Extensible
- Embedded
- Extensive library

## Limitations

- Performance may be lower because it is interpreted.
- The provided material notes limited use for mobile applications.

## Flavors

CPython, Jython/JPython, IronPython, PyPy, RubyPython, and Anaconda Python.

## Versions

Python 1.0, Python 2.0, and Python 3.0 are discussed in the provided material.
